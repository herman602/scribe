# Scribe v0.1.0 release checklist

Status: publication approved; public website deployed; final GitHub gates pending
Release date: Unreleased  
Migration head: `0022`

This checklist separates local evidence from external publication. A checked
local item does not authorize creating a repository, pushing, tagging, or
changing visibility.

## Public boundary

- [x] AGPL-3.0-or-later license and third-party notices are present.
- [x] The tracked-tree scanner rejects credentials, databases, private keys,
  operator paths, private Scribe hosts, and non-example email addresses.
- [x] Real credentials, tokens, databases, backups, logs, email bodies,
  statements, PDF passwords, and account data are absent from the candidate.
- [x] Public examples use loopback addresses and reserved example domains.
- [x] Maintainer-specific LaunchAgents were replaced by generated per-user
  service definitions.
- [x] Internal release-planning files are excluded from the public source tree.
- [x] The public candidate will start from one clean root commit; the private
  pre-release history will not be pushed.

## Documentation and onboarding

- [x] README describes the technical self-hoster audience and the absence of a
  hosted service or one-click installer.
- [x] Installation, user-owned Gmail OAuth, configuration, parser coverage,
  parser contribution, backup/restore, and macOS service guides are linked.
- [x] OAuth setup requires a Desktop client and `chmod 600 credentials.json`.
- [x] The bank-parser guide documents the real interfaces, registry wiring,
  sender rules, encrypted PDFs, synthetic fixtures, tests, and a safe prompt
  for another LLM.
- [x] The dashboard screenshot contains only an empty synthetic installation.

fixed the documentation issue it found in `44550de`. Final packaging checks are
run again after the audit documents are committed.

- [x] `uv sync --extra dev` completed from a fresh clone.
- [x] `uv run python -m app init` created a new database at revision `0022`.
- [x] `doctor --json` passed Python, configuration, filesystem, SQLite, and

- [x] Mocked full/incremental Gmail and bank-parser tests passed: 62 tests.

## Publication blockers

Publication stops if any final scan finds an unreviewed secret, any fresh-clone
step needs undocumented knowledge, either remote workflow is not green, or the
remote contains more history than the approved clean root.
